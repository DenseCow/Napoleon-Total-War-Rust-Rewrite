# Security

Report security problems privately through
[GitHub's private reporting](https://github.com/Rosebuddyy/Napoleon-Total-War-Rust-Rewrite/security/advisories/new),
not in a public issue. This includes anything in the repository that could run code on a
contributor's machine unexpectedly (build scripts, tools, AI-assistant configuration such as
`.mcp.json` or `CLAUDE.md`).

Only the latest `main` is supported.
